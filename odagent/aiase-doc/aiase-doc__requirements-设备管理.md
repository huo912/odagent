# 设备管理模块

## 模块概述

本模块旨在为系统管理员及运维人员提供对设备全生命周期的管理能力。主要功能涵盖设备的检索查询、列表展示、新增录入、信息编辑及删除操作。

## 外部接口需求

### 用户接口

- UI 布局：采用标准的 “顶部搜索栏 + 中部数据表格 + 底部分页器 + 弹窗操作区” 布局。
- 列表页：以表格形式展示设备关键信息。列表包括两列操作列（编辑/详情），在表格中分成两列显示。
- 表单页：新增和编辑功能共用同一表单界面，采用弹出框形式，包含必填项标识（红色星号）和实时校验提示。
- 交互反馈：所有操作（成功/失败）需通过全局消息提示框反馈；删除等危险操作必须弹出二次确认对话框。

### 软件接口

- 内部依赖

  这部分省略，根据项目需求而定

- 数据接口
  1. 输入：接收前端提交的 JSON 格式设备数据。
  2. 输出：返回标准化的结果码（Code）、消息（Message）及设备对象数据。

## 功能需求

### 设备查询与列表展现

- 功能描述

  用户可通过多条件组合筛选设备，并以分页列表形式查看结果。

- 输入
  - 筛选条件：关键字 [ 设备名称或者设备编码 ]（模糊匹配）、设备状态（下拉框显示 在用/停用/维修中）、入库日期开始（日期输入框）、入库日期结束（日期输入框）
  - 排序规则：默认按“创建时间”倒序。
  - 分页参数：一共多少条记录、每页条数（Page Size，默认20，可选10/20/30/40/50/100）页码（Page No）。
- 处理过程
  1. 系统接收筛选参数。
  2. 在数据库中执行复合查询。
  3. 若查询结果为空，列表区显示“暂无数据”。
  4. 若结果存在，渲染表格数据。

- 输出
  - 设备列表表格，包含字段：状态（蓝色-在用/红色-停用/灰色-维修中）、设备名称、设备编码、设备型号、设备位置、入库时间、编辑、详情，编辑和详情在表格中分成两列显示。表格中显示的顺序要一致。
  - 分页控件，显示总记录数、总页数、当前页。

- 异常处理

  若数据库连接超时，提示“服务暂时不可用，请稍后重试”。

### 新增设备

- 功能描述

  允许用户录入新的设备信息并保存至数据库。

- 输入
  - 基本信息：设备名称（必录项）、设备编码（必录项）、设备型号、设备分类（下拉树形式展现）、设备位置、设备状态（下拉框显示 在用/停用/维修中）、设备描述（文本输入域）

- 处理过程
  1. 前置校验：检查设备编码是否已存在；检查必填项是否完整；
  2. 数据持久化：将清洗后的数据写入 business_device 表；
  3. 缓存更新：清除或更新设备列表相关的缓存；
- 输出
  - 成功：关闭表单，刷新列表，提示“新增成功”。
  - 失败：在对应输入框下方显示具体错误原因（如“设备编码已存在”）

- 约束：设备编码在全系统中必须唯一；

### 编辑设备

- 功能描述

  允许用户修改现有设备的信息。

- 输入
  - 用户从列表中点击“编辑”，系统加载该设备当前所有数据至表单（与新增设备一致，通过弹出框显示）。
  - 用户修改设备属性。
- 处理过程
  1. 变更校验：同“新增设备”的校验逻辑。
  2. 数据更新：执行 UPDATE 操作，更新 modify_user 和 modify_time。
- 输出
  - 成功：提示“保存成功”，列表自动刷新以展示最新数据。
  - 失败：提示“数据修改失败”或具体校验错误。

### 删除/停用设备

- 功能描述

  提供逻辑删除功能，确保历史维护记录数据完整性。

- 输入
  - 批量删除：勾选多条记录后，点击顶部“批量删除”按钮。

- 处理过程
  1. 二次确认：弹出对话框“您确认要删除所选择的内容吗？“。
  2. 逻辑执行：

     策略：本系统采用逻辑删除。不物理删除数据库记录，仅将 deleted 字段更新为“1”。

- 输出
  - 成功：列表移除该条目，提示“删除成功”。
  - 失败：提示具体原因。

- 异常处理

  提示具体异常信息

### 查看详情

- 功能描述

  用户点击列表中的详情按钮，可以查看设备详情功能。

- 输入
  - 点击详情按钮

- 处理过程
  1. 根据id调用后端api接口，返回设备详情信息。
  2. 通过路由跳转方式，将设备详情信息以表单形式显示到页面中。

- 输出
  - 成功：跳转路由，并显示设备详情。
  - 失败：提示具体原因。

- 异常处理

  提示具体异常信息
